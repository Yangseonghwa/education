# AI 자동 채점 (AI Auto-Grading for Google Sheets & Classroom)

Google 스프레드시트와 Google Apps Script 기반의 **Classroom Google Docs 제출물 AI 자동 채점 도구**입니다. Google Drive 내 `Classroom`(또는 `클래스룸`) 폴더의 학생 제출물(Google Docs)과 교사용 정답지(Google Docs)를 비교하여 **OpenAI 호환 API**, **OpenAI Responses API**, **Anthropic Claude API**, 또는 **Google(Gemini) API**로 자동 채점하고, **`과제명_모델명_채점일시` 형식의 개별 결과 시트**에 채점 결과와 피드백을 기록합니다.

---

## 주요 기능

- **설정 시트(`AI채점_설정`) 기반 프리셋(URL 엔드포인트 & API Key) 선택**:
  - 스프레드시트 내 `AI채점_설정`(또는 `설정`, `API설정`, `API_설정`, `Config`) 시트에 자주 사용하는 **프리셋 이름, API 규격, Base URL, API Key, 기본 모델, 비고**를 저장해 두고 사이드바 드롭다운에서 즉시 선택하여 사용할 수 있습니다.
  - 사이드바의 **[시트 열기]** 버튼으로 설정 시트를 자동 생성·활성화할 수 있으며, **[새로고침]** 버튼으로 시트에 입력한 프리셋 목록을 즉시 다시 불러올 수 있습니다.
  - 보안을 위해 클라이언트 UI에는 마스킹된 키(`AIza...7890`)만 표시되고 실제 API 호출은 서버(`Code.gs`)에서 안전하게 수행됩니다.
- **4종 AI API 제공자/규격 및 동적 모델 목록 조회**:
  - `OpenAI 호환 · Chat Completions` (`/chat/completions`, 기본 Base URL: `https://api.openai.com/v1`)
  - `OpenAI · Responses` (`/responses`, 기본 Base URL: `https://api.openai.com/v1`)
  - `Claude · Messages` (`/messages`, 기본 Base URL: `https://api.anthropic.com/v1`, `x-api-key` 및 `anthropic-version: 2023-06-01` 헤더)
  - `Google(Gemini)` (`/models/{model}:generateContent` 및 `/v1beta/openai` 호환 엔드포인트 자동 판별, 기본 Base URL: `https://generativelanguage.googleapis.com/v1beta`, `x-goog-api-key` 헤더 및 `responseMimeType: "application/json"` 지원)
  - 입력창의 API 키 또는 선택한 설정 시트 프리셋의 API 키로 각 제공자의 `/models` 엔드포인트를 실시간 호출하여 사용 가능한 모델 목록을 드롭다운에 동적으로 표시합니다.
- **학생 이름 정제 및 외부 API 전송 시 개인정보 보호(익명화)**:
  - **학생 이름 정제 (`cleanStudentName_`)**: Google Classroom 제출물 파일명에 붙는 과제명 접두사/접미사(예: `샤를 법칙 탐구 - 홍길동`, `[중1 과학] 홍길동의 사본.docx`, `홍길동 (제출본)`)를 자동으로 제거하여 사이드바 미리보기와 결과 시트에 **순수 학생 이름**만 깔끔하게 표시합니다.
  - **외부 LLM API 익명화 전송**: 채점 요청을 외부 AI API로 전송할 때 실제 학생 이름과 문서 제목을 **`학생_1`, `학생_2` ... / `제출물_1`, `제출물_2` ...** 로 변환하고 본문 내 학생 실명도 마스킹하여 전송합니다. 채점 완료 후 로컬 스프레드시트 결과 시트에는 원래의 실제 학생 이름과 매칭하여 기록합니다.
- **동일 과제 재채점 시 별도 결과 시트 생성 & 모델·일시 시트명 표기**:
  - 결과 시트 제목을 **`과제명_모델명_YYYYMMDD_HHMMSS`**(예: `샤를법칙탐구_gemini-2.5-flash_20261108_093015`) 형식으로 자동 생성하여 사용된 모델과 채점 일시를 한눈에 파악할 수 있습니다.
  - 동일한 과제를 다른 모델이나 다른 시점에 다시 채점하더라도 기존 결과 시트를 덮어쓰지 않고 항상 새로운 개별 결과 시트를 생성합니다(충돌 시 `_2`, `_3` 자동 부여).
- **완료/실패 목록 일괄 삭제 (`clearFinishedJobs`)**:
  - 사이드바 하단의 **[완료/실패 목록 전체 삭제]** 버튼 또는 상단 메뉴(**AI 자동 채점 > 완료/실패 작업 일괄 삭제**)를 통해 완료(`DONE`), 실패(`ERROR`), 중단(`STOPPED`) 상태의 작업 기록을 한 번에 정리할 수 있습니다(이미 생성된 결과 시트는 그대로 보존됩니다).
- **정량 / 정량+정성 채점 모드 및 AI 사용 의심 신호 분석**:
  - **정량평가만 반영** 또는 **정량 + 정성평가 모두 반영** 모드를 선택할 수 있으며, 선택 시 서술형 문장의 AI 작성 의심 수준(`high` / `medium` / `low`), 점수(`0~100`), 판단 이유 및 근거 문장을 함께 기록합니다.
- **안정적인 백그라운드 예약 큐 및 성능 최적화**:
  - `PropertiesService` 일괄 읽기/삭제(`removeJobs_`), 과제 등록 시 설정 저장 단일 RPC 통합, Drive 폴더 메타데이터 재사용 등을 통해 불필요한 RPC 및 I/O 호출을 최소화했습니다.

## 설치 방법

1. Google 스프레드시트를 새로 만들거나 기존 채점용 스프레드시트를 엽니다.
2. 상단 메뉴에서 **확장 프로그램 > Apps Script**를 클릭합니다.
3. 프로젝트에 다음 두 파일을 구성합니다:
   - `Code.gs`: 이 폴더의 `Code.gs` 전체 내용을 복사하여 붙여넣습니다.
   - `sidebar.html`: 파일 추가(`+` > **HTML**)로 이름을 `sidebar`(`sidebar.html`)로 지정한 뒤, `sidebar.html` 내용을 붙여넣습니다.
4. *(권장)* 좌측 **서비스(`+`)** 메뉴에서 **Google Drive API (`Drive`, v3)** 서비스를 추가합니다.
   - 공유 드라이브 탐색 및 빠른 폴더/문서 목록 조회에 사용됩니다. 추가하지 않아도 기본 `DriveApp` 폴백으로 내 드라이브 탐색이 동작합니다.
5. 프로젝트를 저장(`Ctrl+S`)하고 스프레드시트를 새로고침하면 상단에 **AI 자동 채점** 메뉴가 나타납니다.

## 설정 시트(`AI채점_설정`) 구성 방법

사이드바를 처음 열거나 상단 메뉴에서 **AI 자동 채점 > 설정 시트 열기/생성**을 클릭하면 `AI채점_설정` 시트가 자동으로 생성됩니다.

| 열 순서 | 머리글 | 설명 | 예시 |
|:---:|---|---|---|
| A | `프리셋 이름` | 사이드바 드롭다운에 표시할 이름 | `Google Gemini 교사용` |
| B | `API 규격` | `chat_completions`, `responses`, `claude`, `gemini` (비워두면 URL/이름으로 자동 추론) | `gemini` |
| C | `Base URL` | API 엔드포인트 기본 주소 (비워두면 규격별 기본 URL 자동 적용) | `https://generativelanguage.googleapis.com/v1beta` |
| D | `API Key` | 해당 엔드포인트에서 사용할 API 키 | `AIzaSy...` |
| E | `기본 모델` | 프리셋 선택 시 기본으로 채울 모델 ID (선택 사항) | `gemini-2.5-flash` |
| F | `비고` | 프리셋 설명 메모 (선택 사항) | `과학과 공용 키` |

## 사용 방법

1. 스프레드시트 상단 메뉴에서 **AI 자동 채점 > 채점 사이드바 열기**를 클릭합니다.
2. **API 설정 (프리셋 선택 또는 직접 입력)**:
   - **설정 시트 프리셋** 드롭다운에서 `AI채점_설정` 시트에 저장해 둔 프리셋을 선택하면 API 규격, Base URL, API 키가 자동 적용되고 사용 가능한 모델 목록이 즉시 조회됩니다.
   - 또는 **API 규격**, **Base URL**, **API 키**를 직접 입력하고 **[불러오기]**를 눌러 모델 목록을 조회한 뒤 모델을 선택합니다.
3. **채점 대상 선택**:
   - **과제 폴더 선택** 영역에서 `Classroom › <수업 폴더> › <과제 폴더>`로 이동하면 과제명이 제거된 순수 학생 이름 미리보기가 표시됩니다. 확인 후 **과제 폴더 확정** 버튼을 클릭합니다.
   - **정답지 폴더 탐색** 영역에서 정답지 Google Docs 문서를 선택합니다.
4. **채점 방식 설정 및 실행**:
   - 점수 반영 범위, 만점, 최대 출력 토큰, AI 사용 의심 분석 여부를 확인하고 **예약 큐에 추가**를 클릭합니다.
   - 하단 **예약 큐 확인** 영역에서 생성될 결과 시트 이름(`과제명_모델명_YYYYMMDD_HHMMSS`)을 확인하고 **예약 큐 전체 실행**을 클릭하면 채점이 시작됩니다.
   - 채점이 끝난 뒤 **[완료/실패 목록 전체 삭제]** 버튼으로 작업 큐 목록을 깔끔하게 비울 수 있습니다.

## 결과 시트 구성 (`과제명_모델명_YYYYMMDD_HHMMSS`)

채점 실행마다 과제명, 모델명, 채점 일시가 포함된 고유 시트가 새로 생성되며 다음 17개 열이 기록됩니다:

| 열 순서 | 열 이름 | 설명 |
|:---:|---|---|
| 1 | `학생명` | 과제명 접두사/접미사 및 불필요한 표기가 제거된 순수 학생 이름 |
| 2 | `점수` | 최종 반영 점수 (만점 기준 클램핑 및 소수 둘째 자리 반올림) |
| 3 | `만점` | 설정한 과제 만점 |
| 4 | `AI 의심` | `high` / `medium` / `low` / `not_checked` |
| 5 | `AI 의심 점수` | `0 ~ 100` (미검사 시 `0`) |
| 6 | `정성점수` | 서술형·정성평가 점수 (`정량만` 모드일 때는 `0`) |
| 7 | `피드백` | 학생별 채점 피드백 요약 (익명 식별자는 실제 학생명으로 자동 복원) |
| 8 | `신뢰도` | AI 채점 신뢰도 (`high` / `medium` / `low`) |
| 9 | `채점일시` | 채점 기록 시각 |
| 10 | `클래스` | Classroom 수업 폴더명 |
| 11 | `과제` | 과제 폴더명 |
| 12 | `학생ID` | 학생 식별자 (폴더 기반 수집 시 공란) |
| 13 | `학생 답안` | 학생 제출물 Google Docs 편집 링크 |
| 14 | `정답지` | 기준 정답지 Google Docs 편집 링크 |
| 15 | `AI 의심 이유` | AI 사용 의심 판단 근거 요약 |
| 16 | `AI 의심 근거` | 답안에서 발췌한 근거 문장 (`\|` 구분) |
| 17 | `작업ID` | 예약 큐 작업 고유 UUID |
