## 2. v3.1 핵심 업그레이드: ‘자동 피드백 추출 및 지침 개선 루프’ 작동 방식

교사가 매번 `"이걸 내 성향으로 기억해줘"`라고 일일이 명령하지 않아도, 일상적인 수업 준비 대화만으로 내 스타일이 자동 축적됩니다.

```
[1. 시나리오 작업]
교사가 B-2 블록 선택 + "설명을 줄이고 반례 질문을 먼저 던져줘" 수정 지시
   │
   ▼ (백그라운드 자동 채굴 & 델타 분석)
[자동 추출 엔진] D2(발문 톤앤매너) 시그널 감지 → 장부에 자동 기록
   │
   ├─▶ (마이크로 루프: Forward-Propagation)
   │    다음 단계인 `/프리젠테이션` 및 `/학습지` 생성 시 교사가 다시 말하지 않아도
   │    자동으로 '설명 축소 + 반례 질문 우선' 스타일이 슬라이드와 학습지에 선반영됨!
   │
   └─▶ (확정 시 원클릭 승격 브리핑)
        `/시나리오-확정`, `/학습지-확정` 응답 하단에 자동으로
        [🤖 자동 추출 성향 브리핑 & 원클릭 승격 제안] 배너 출력!
        교사가 "성향 승인" 한 마디만 하면 2-C 영구 프로필(D1~D6)로 즉시 승격!
           │
           ▼
[2. 수업 설계 완료 시 지침 진화]
   ├─ `/성향스냅샷` 입력 → Google Docs 지침의 `2-C` 섹션 덮어쓰기용 패치 블록 10초 출력
   └─ `/지침개선` → `/지침개선-확정` 입력 → 단원 소재를 보편 원칙으로 정제·병합한 v3.2 지침 전문 출력
```
